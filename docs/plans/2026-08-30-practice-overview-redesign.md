# 卡包练习概览重设计

## 问题

旧版将卡包标题、完成图标、三项结果、完成率、练习次数和建议分散在多个位置。三项结果被压进一行，主次相近，用户无法快速判断本轮练习目标。

## 方案

采用“目标优先”的单一信息容器：

- 顶部左对齐展示卡包名称、内容分类和卡片总数。
- 概览容器以“本轮练习 N 张”为唯一主数字。
- 掌握分布使用一条连续比例条表达，再以三列小统计给出精确数量。
- 完成率和累计练习次数放在容器底部同一基线，作为辅助信息。
- 页面底部只保留“开始练习”主按钮。

不使用环形图、独立统计卡或卡片预览列表，避免增加视觉噪音和双层卡片。

## 验收

- 所有内容使用 32 px 页面边距和统一左基线。
- 用户首先看到本轮卡片数量，其次看到掌握分布。
- 390×844 下无裁切、重叠或拥挤。
- 现有进入练习页的交互保持不变。

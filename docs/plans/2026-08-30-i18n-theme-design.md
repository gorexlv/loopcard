# LoopCard i18n 与主题设计

## 目标

LoopCard 默认跟随设备语言，并支持在应用内覆盖语言设置。首批覆盖简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语、葡萄牙语和俄语。界面语言只影响产品导航、操作与状态文案，不改写用户卡片内容。

主题提供跟随系统、浅色和深色三种模式。深色保持现有原型的紫黑渐变和半透明卡片；浅色沿用青色品牌色，使用低饱和浅紫背景、深色文字和白色玻璃表面。语言与主题选择均保存到本地。

## 架构

- `AppLocalizations` 提供十种语言的界面词典、区域回退和参数化文案。
- `AppSettingsStore` 使用 `SharedPreferencesAsync` 持久化 locale 与 theme mode。
- `LoopCardApp` 持有当前设置，并向 `ProfileScreen` 注入修改回调。
- `LoopPalette` 作为 `ThemeExtension` 提供随主题变化的文字、表面、边框和弱化色。
- 卡包示例内容保持原语言；卡包标题、类别、练习状态和操作文案由本地化层提供。

## 验证

- 单元测试覆盖十种 locale 的解析与回退。
- Widget 测试覆盖英语切换、深浅主题切换和设置持久化。
- 视觉基准继续以简体中文深色主题为主，并额外检查英文浅色页面。
- 最终执行完整 `flutter test` 与 `flutter analyze`。

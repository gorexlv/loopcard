# LoopCard “记忆回路”开屏设计

## 目标

把开屏从单纯 Logo 展示升级为一次简短的产品叙事：零散的纸张卡片归拢成一张可复习的记忆卡，彩色回路完成闭环，表达“让记忆，循环发生”。

## 视觉结构

- 背景固定使用深靛紫品牌色，叠加克制的紫红渐变，保证 Android 原生启动页与 Flutter 首帧连续。
- 画面中心是三张轻微错位的纸张卡片；正面使用暖白纸色、横向笔记线与珊瑚色页边线，延续单词卡的视觉语言。
- 卡片背后绘制青绿、琥珀、珊瑚三色记忆回路，作为 LoopCard 的产品隐喻。
- 下方仅保留品牌名、文案“让记忆，循环发生”和静态三色签名，不放加载器或伪进度。

## 动效节奏

- 0–460ms：品牌背景和纸张纹理显现。
- 70–580ms：三张卡片由松散状态归拢，不使用回弹。
- 220–840ms：记忆回路沿路径完成绘制。
- 530–1010ms：品牌名与标语淡入并轻微上移。
- 约 1400ms 后进入后续流程。

当系统开启“减少动态效果”时，直接展示最终构图，不执行位移、缩放或路径动画。

## 原生启动衔接

Android 12 及以上使用深靛紫启动背景与居中品牌图标；旧版本使用同色渐变与同一图标。Flutter 第一帧以相同底色和居中图标起步，避免白屏和视觉跳变。

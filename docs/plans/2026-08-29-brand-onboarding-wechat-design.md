# LoopCard 品牌、首次引导与微信登录设计

## 品牌方向

Logo 使用一条连续的青绿色莫比乌斯带形成循环，右上角折出卡片页角，交叉处以一小段琥珀色标记“记忆被再次唤起”。产品 Logo 由图形与 Inter 字标 `LoopCard` 组成；App Logo 使用独立图形和原有暮色渐变底色，确保小尺寸仍能识别 loop 与 card。

## 首次启动

每次冷启动显示约 1.8 秒品牌动画：Logo 从较小比例和低透明度进入，轻微上浮，字标和标语随后出现。首次使用继续进入三步问卷：

1. 卡片来源：拍照生成 / 导入文本 / 手动创建。
2. 记忆节奏：少量试记 / 稳定循环 / 集中处理。
3. 每日目标：10 / 20 / 30 张。

问卷采用单选大行、统一左边距和底部主按钮，不使用卡片嵌套。选择保存在本机；完成后进入登录页，可微信登录或暂时跳过。

## 微信登录

客户端通过 WeChat SDK 请求 `snsapi_userinfo` 授权，仅取得一次性 code。AppSecret 与 access token 交换必须留在服务端；客户端向 `WECHAT_AUTH_ENDPOINT` 提交 code 并接收最小用户资料。缺少 AppID、未安装微信、用户取消、服务端未配置均显示明确反馈，不伪造成功状态。当前无后端时仍可完成 SDK 接线、配置检测和授权入口，用户可以跳过后使用全部本地卡片功能。

## 状态与测试

首次引导状态、问卷答案和最小登录展示信息使用 `SharedPreferencesAsync` 保存。测试覆盖首次进入、三步选择、跳过登录、已完成用户直达首页、微信配置缺失与授权错误。新增页面以 390×844 金图进行视觉检查。

# 设置页多语言与双主题补齐设计

## 目标

在“我的 → 设置”中提供界面语言与外观入口，保留现有十种语言，并保证每种语言的界面词条完整；提供跟随系统、浅色和深色三种外观选择，用户选择在重启后继续生效。

## 现状与方案

项目已经具备 `AppLocalizations`、`LoopPalette`、SharedPreferences 设置存储，以及设置页的语言/外观底部选择器。本次不迁移 ARB，也不引入额外状态管理，而是在现有结构上补齐缺口。语言保留英文、简体中文、繁体中文、日文、韩文、西班牙文、法文、德文、葡萄牙文和俄文；系统区域解析继续区分简繁中文。

审计显示英文和两种中文各有完整的 108 个常规界面键，其余七种语言各缺 13 个键。补齐后，设置提示、微信登录状态、练习结果与功能占位提示不再回退为英文。卡包和卡片的用户内容仍按原始数据展示，不属于界面本地化范围。

主题继续通过 MaterialApp 的 `theme`、`darkTheme`、`themeMode` 和 `LoopPalette` 提供。浅色与深色分别控制页面背景、渐变、玻璃表面、边框、分隔线和文字；青绿色按钮的深色前景保留以维持可读对比度。设置变更立即刷新应用，并由 SharedPreferences 保存。

## 验证

新增翻译完整性测试，逐语言验证所有基准键都存在且关键缺失项不再回退英文。保留并扩展运行时设置测试，验证语言和主题从设置页切换并持久化。最终运行全量测试、静态分析和 Android 构建。

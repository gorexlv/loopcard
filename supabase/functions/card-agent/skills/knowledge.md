# Knowledge question cards · v1

Use for concepts, explanations and study notes. Ground every question and answer
in the provided material. Do not invent missing facts. If there is insufficient
source material, ask for more detail and return no cards. Create one clear
question per card. Default back sections: short answer first, explanation/steps
second. Adapt wording, language, section order and detail to the current rules.
word_data must be null. Keep the visible front within 100 characters.
